# class-placement — 분반 배치 시스템

학교 현장에서 학생을 여러 반으로 나눠 균형 있게 배치(분반)하는 웹 애플리케이션입니다.
엑셀 학생 명단을 업로드하면 성적·성별을 고려한 **남녀 성비 균형 ㄹ자 알고리즘**으로 학급을 자동 편성하고, 분리 대상자(동시 분반 금지) 충돌 알림, 드래그앤드롭 수동 조정 및 스마트 맞교환 추천을 제공합니다.
별도 서버나 백엔드 없이 **브라우저 단독(단일 HTML 파일)** 으로 동작하여 학생 개인정보가 외부로 절대 유출되지 않습니다.

---

## 🌟 주요 특징 및 최신 개선 사항

1. **🔒 100% 오프라인 & 개인정보 안전**
   - React, ReactDOM, Babel, SheetJS 등 필수 라이브러리를 단일 HTML에 내장.
   - 외부 서버 통신이 전혀 없으며, 새로고침해도 브라우저 `localStorage`에 자동 저장·복원됩니다.
   - 상단 **`오프라인 HTML 저장`** 버튼으로 인터넷이 끊긴 학교 교육행정망(NEIS) PC나 USB에서 바로 쓸 수 있는 단일 HTML을 즉시 내려받을 수 있습니다.
2. **🏫 중학교 & 고등학교 맞춤 분반 환경 지원**
   - **학교급**: 중학교 및 고등학교(고1→고2, 고2→고3, 고입 신입생 반배정) 완전 지원.
   - **성별 유형**: 남녀공학(성비 균형 ㄹ자), 남학교/여학교(단일 성적순 ㄹ자, 성별 컬럼 불필요) 맞춤 선택.
   - **학번 체계**: 학급 수 감소 추세에 맞춘 **4자리 학번(2101형)** 및 과밀학교 **5자리 학번(20101형)** 선택 지원 (10반 이상은 5자리 학번 자동 안전 전환).
3. **⚖️ 남녀 성비 균형 ㄹ자(Snake) 알고리즘**
   - 남녀공학의 경우 남학생 순방향(1→N), 여학생 역방향(N→1) 교차 배치를 적용하여 학급별 남녀 성비(12~13명)와 성적 총점 평균을 완벽하게 동시 수렴합니다.
4. **🚀 1초 샘플 체험 모드 & 템플릿 다운로드**
   - 엑셀 파일이 준비되지 않은 교사도 첫 화면에서 선택한 학교 환경(중/고, 공학/남/여, 학번)으로 클릭 한 번에 가명 샘플 데이터(194명, 분리대상 25건)를 즉시 로드하여 모든 기능을 체험할 수 있습니다.
   - 학생 데이터 엑셀 양식 및 분리 대상 양식도 첫 화면에서 바로 다운로드 가능합니다.
5. **🏫 유연한 학급 수 (2반~20반) 지원**
   - 상단 `[-] N반 [+]` 컨트롤로 학급 수를 자유롭게 증감할 수 있으며, 결과 엑셀 내보내기 시 학번 오버플로를 완벽 방지합니다.

## 📁 프로젝트 구조

```
class-placement/
├── index.html               # 실행본 및 GitHub Pages 배포본 (단일 파일, 약 4.1MB)
├── guide.html               # 교사용 상세 사용설명서
├── 학생데이터_샘플.xlsx      # 학생 명단 엑셀 템플릿
├── 분리대상_샘플.xlsx        # 분리 학생 엑셀 템플릿
│
├── src/                     # 모듈형 개발 소스
│   ├── app.jsx              # React 앱 메인 UI 및 분반 로직
│   ├── assets.js            # 폭탄 아이콘 등 Base64 이미지 자산
│   └── sample_data.js       # 1초 체험용 내장 샘플 데이터 (가명 194명)
│
└── tools/                   # 빌드 및 검증 도구
    ├── build.py             # src + preamble/epilogue -> index.html 단일 파일 생성기
    ├── preamble.html        # 내장 라이브러리 (React, Babel, SheetJS)
    ├── epilogue.html        # HTML 닫는 태그
    ├── test_algorithm.py    # 성비 및 성적 균형 분반 알고리즘 검증 테스트
    └── verify_html.cjs      # 번들링 무결성 검증 스크립트
```

---

## 🛠️ 개발 및 빌드 방법

소스를 수정한 뒤에는 `build.py`를 실행하여 배포용 `index.html`을 생성합니다:

```bash
# 단일 배포본(index.html) 빌드
python tools/build.py

# 분반 알고리즘 성비·성적 균형 검증 테스트
python tools/test_algorithm.py

# 번들 무결성 검증
node tools/verify_html.cjs
```

## 📖 사용 설명서

- `guide.html`을 웹 브라우저로 열면 엑셀 작성 요령, 분반 규칙 설정, 드래그앤드롭 조정 방법 등을 단계별로 확인할 수 있습니다.
