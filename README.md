# 🎓 중·고등학교 분반 배치 시스템 (Class Placement)

> **"폭탄 돌리기 방지 • 데이터 기반 공평 균등 학급 편성"**  
> 전국의 중학교 및 고등학교 교사들이 새 학년 반 편성 시 성적·성비·교우관계를 공정하고 신속하게 맞출 수 있도록 돕는 오프라인 지원 단일 파일 웹 애플리케이션입니다.

- **🌐 라이브 웹 앱 (GitHub Pages)**: [https://getbetterwithu.github.io/class-placement/](https://getbetterwithu.github.io/class-placement/)
- **🔒 오프라인 지원**: 인터넷이 완전히 차단된 학교 교육행정망(NEIS) 컴퓨터에서도 더블클릭만으로 즉시 구동되는 **단일 독립형 HTML (`index.html`, 4.17MB)**

---

## 🌟 핵심 특징 및 주요 기능

### 1. 🔒 100% 오프라인 & 개인정보 안전
- React, ReactDOM, Babel, SheetJS 등 필수 런타임을 `index.html` 단일 파일 내에 Base64/인라인으로 완전 내장.
- 외부 서버 통신이 일절 발생하지 않으며, 학생 명단과 성적 정보가 컴퓨터 밖으로 1바이트도 유출되지 않습니다.
- 상단 **`오프라인 HTML 저장`** 버튼을 누르면 학교 업무망 PC나 USB에 소장 가능한 오프라인 HTML을 즉시 다운로드할 수 있습니다.

### 2. ⚡ 인라인 스마트 맞교체 인터랙션 (불 켜짐/꺼짐 시스템)
- **번거로운 팝업 모달 완전 제거**: 학생을 클릭했을 때 시야를 가리던 교체 추천 팝업창을 완전히 없앴습니다.
- **초록색 불 점등 (`🔄 교체가능`)**: 학생을 클릭하면 다른 모든 반에서 성적이 비슷한 호환 범위(±4위 등)의 학생 카드에 에메랄드 초록 불이 켜지며 클릭 가능한 상태가 됩니다.
- **불 꺼짐 및 분리 충돌 방지 (`🚫 분리충돌`)**: 맞교체했을 때 어느 한쪽이라도 분리 대상과 같은 반이 되는 학생은 38% 투명도로 딤드 처리되며 불이 꺼져 클릭이 차단됩니다.
- **원클릭 즉시 교체**: 초록 불이 켜진 학생을 클릭하면 그 자리에서 1초 만에 맞교체되고 원래 보드로 복귀합니다 (`Esc` 키나 취소 버튼으로 언제든 취소 가능).

### 3. 🚫 분리 학생 관리 모달 (`SeparationModal`)
- 본문 작업 공간을 크게 차지하던 분리 대상 목록을 전용 팝업 다이얼로그로 격리 수납했습니다.
- 상단 툴바의 **`[ 🚫 분리 학생 관리 (N쌍) ]`** 버튼을 눌러 언제든 엑셀 파일 드래그 앤 드롭 업로드 및 수동 추가/삭제를 수행할 수 있습니다.

### 4. 🏠 시작 화면 복귀 & 브라우저 히스토리 (URL Hash 라우팅)
- 워크스페이스 상단 헤더에 **`[ 🏠 시작 화면으로 돌아가기 ]`** 전용 버튼을 배치했습니다.
- `#home`과 `#workspace` 간 URL 해시 동기화를 적용하여, 웹 브라우저의 '뒤로가기(←) / 앞으로가기(→)' 버튼으로도 작업 손실 없이 자연스럽게 복귀할 수 있습니다.

### 5. 🧪 다른 조건으로 테스트하기 (108가지 분반 시뮬레이터)
- 학교급(중/고) × 성별(공학/남/여) × 학번(4/5자리) × 반수(4/8/12반) × 진급(1to2/2to3/freshman)의 **108가지 모든 환경 순열을 100% 전수 검증**한 시뮬레이터 모달을 탑재했습니다.

### 6. ⚖️ 남녀 성비 균형 ㄹ자(Snake) 알고리즘
- 남녀공학의 경우 남학생 순방향(1→N), 여학생 역방향(N→1) 교차 배치를 적용하여 학급별 남녀 성비와 성적 총점 평균을 완벽하게 동시 수렴합니다.

### 7. 🎨 세련된 프리미엄 Slate/Indigo SaaS UI
- 눈부신 무지개 원색 그라디언트와 촌스러운 주황색 박스를 걷어내고, 슬레이트(Slate) & 인디고(Indigo) 기반의 깔끔하고 정돈된 프리미엄 SaaS 룩앤필로 리팩토링했습니다.

## 📁 프로젝트 구조

```
class-placement/
├── index.html               # 최종 단일 배포 파일 & GitHub Pages 실행본 (약 4.17MB)
├── guide.html               # 교사용 상세 사용설명서
├── HANDOVER.md              # 프로젝트 인계 및 히스토리 기록 문서
├── 학생데이터_샘플.xlsx      # 학생 명단 엑셀 템플릿
├── 분리대상_샘플.xlsx        # 분리 학생 엑셀 템플릿
│
├── src/                     # 개발 소스
│   ├── app.jsx              # React 앱 메인 UI, 인라인 맞교체, 분리 모달, 분반 알고리즘
│   ├── assets.js            # 폭탄 아이콘 등 Base64 이미지 자산
│   └── sample_data.js       # 1초 체험용 내장 샘플 데이터 (실제 학생명 194명)
│
└── tools/                   # 빌드 및 검증 도구
    ├── build.py             # src + preamble/epilogue -> index.html 단일 파일 빌더
    ├── test_matrix.py       # 108가지 분반 환경 전수 검증 테스트 러너
    ├── test_compile.js      # 크로스플랫폼 Babel 컴파일 검증기
    ├── preamble.html        # 내장 라이브러리 (React, Babel, SheetJS)
    └── epilogue.html        # HTML 닫는 태그
```

## 🛠️ 개발 및 빌드 방법

소스를 수정한 뒤에는 `build.py`를 실행하여 배포용 `index.html`을 생성합니다:

```bash
# 1. 단일 배포본(index.html) 빌드 및 Babel 구문 검증
python3 tools/build.py

# 2. 108가지 분반 환경 전수 검증 매트릭스 테스트
python3 tools/test_matrix.py
```

## 📖 사용 방법

1. **온라인 접속**: [GitHub Pages](https://getbetterwithu.github.io/class-placement/)에 접속합니다.
2. **샘플 둘러보기**: 첫 화면의 `[ ✨ 194명 실제 샘플로 1초 만에 바로 체험하기 ]` 버튼을 누르면 가명 샘플 명단으로 즉시 분반 배치가 완료됩니다.
3. **우리 학교 명단 업로드**: 교무실 나이스(NEIS)에서 내려받은 학생 명단 엑셀(반, 번호, 성명, 성적, 성별)을 업로드합니다.
4. **분리 학생 등록**: 상단 툴바의 `[ 🚫 분리 학생 관리 ]`를 눌러 분리 명단을 올리거나 수동 입력합니다.
5. **인라인 맞교체**: 교체할 학생을 클릭하면 초록 불이 켜진 학생 중에서 바로 클릭하여 맞교체합니다.
6. **결과 다운로드**: 상단의 `[ 📊 엑셀 다운로드 ]`를 누르면 분반 명렬표 및 신학번 부여 명단이 포함된 엑셀 파일이 즉시 저장됩니다.
